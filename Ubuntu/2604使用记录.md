### Ubuntu 26.04的使用笔记
- 配置中文显示；使用最小模式安装后，显示中文异常。
  - 执行locale charmap，输出ANSI_X3.4-1968。正常应该是UTF-8
  1. 安装确实的语言包
     ```bash
     sudo apt update && sudo apt install language-pack-zh-hans
     ```
  2. 重新配置 locale 列表：
     ```bash
     sudo dpkg-reconfigure locales，并在列表中勾选对应的 UTF-8（例如 en_US.UTF-8 或 zh_CN.UTF-8）。
     ```
- 设置时间为24小时制
  ```bash
   echo "LC_TIME=en_DK.UTF-8" >>/etc/default/locale

   # 重新登录生效
   ```
- 设置时区为上海
  ```bash
  timedatectl set-timezone "Asia/Shanghai"
  ```
- 图形界面更换源，2604 LTS 默认不预装“软件和更新”图形化工具，需要手动安装。安装完毕，再次打开software & Update，就可以选择镜像源
  ```bash
  apt install software-properties-gtk -y
  ```
- 安装中文输入法
  ```bash
  apt install fcitx5 fcitx5-chinese-addons -y

  # 在language support 中 配置 keyboard input method system 选择为fcitx5 。重启系统生效

  # 执行 fcitx5 启动fcitx进程

  # 执行 fcitx 5 configuration 配置fcitx。添加pinyin输入法
  ```
